VANTA — Personal OS v5.0
GitHub Pages / PWA-ready build.

V5 adds:
- Premium redesigned command center and organized feature hub
- Personal Routine Generator (rule-based, local, no API key required)
- Custom Routine Studio with add/remove and drag-reorder
- Life Modes: Normal, Study, Work, Exam, Travel, Busy Day, Recovery
- Adaptive Day, Minimum Day, Comeback and Simplify Day flows
- Energy-based routine guidance
- Goals + Today's 3 Missions
- Mind Space, mood, breathing, grounding, night debrief
- Deep Insights, personal snapshot, weekly review
- Personal profile + routine generation
- Lightweight device-generated SFX and Reduce Motion setting
- Existing V4 tracking/data retained; V5 state is stored separately

Deployment:
1. Extract this ZIP.
2. Upload/replace the extracted files in the GitHub repository root.
3. Keep index.html, manifest.json, sw.js and assets directly in root.
4. GitHub Pages will update automatically.
5. Re-scan the Pages URL in PWABuilder.
